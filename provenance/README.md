# Provenance catalogue

This directory records *where a candidate list was obtained*, when that source was last checked, and the appropriate confidence boundary.

- `source-catalog.json` is a public registry of sources.
- `canonical-replacement-database` is suitable for ID-level membership comparison.
- `discovery-only` sources provide candidate track names only; they must not be treated as proof that an audio file is uncensored.

The catalogue deliberately stores no credentials, local library paths, or audio files.
